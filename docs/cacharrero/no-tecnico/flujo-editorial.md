# Flujo editorial diario

## Flujo paso a paso

1. Abre cliente Git visual y ejecuta `Fetch` + `Pull`.
2. Abre Obsidian sobre el vault de contenido.
3. Edita solo los archivos asignados para tu turno.
4. Revisa formato, enlaces e imágenes.
5. Regresa al cliente Git visual.
6. Haz commit con mensaje descriptivo.
7. Haz push.

## Estructura base de contenido (referencia)

- `content/es/solve/`
- `content/es/inspire/`
- `content/es/glossary/`
- `content/es/disconnected/`
- `content/es/answers-comments/`
- `content/assets/images/`
- `content/assets/videos/`
- `content/assets/files/`

## Reglas de edición

- Nombres en minúscula y guiones.
- No mezclar varias tareas distintas en un solo commit.
- Incluir texto alternativo en imágenes.
- Mantener frontmatter consistente.
