# Markdown basico

## Encabezados

```md
# Titulo principal
## Seccion
### Subseccion
```

## Listas

```md
- item uno
- item dos
```

## Enlaces e imagenes

```md
[Texto del enlace](https://ejemplo.org)
![Texto alternativo](../../assets/images/mi-imagen.webp)
```

## Bloques de codigo

```md
~~~bash
npm run build
~~~
```

## Tip

Siempre guarda el archivo con extension `.md` y nombre en minusculas con guiones.
