# Subir cambios con GitHub Desktop

## Paso a paso

1. `Fetch origin` y luego `Pull origin`.
2. Editar en Obsidian.
3. Revisar diff archivo por archivo.
4. Seleccionar solo cambios intencionales.
5. Commit descriptivo.
6. `Push origin`.

## Si hay error de push

No forzar. Hacer `Pull`, resolver conflicto y publicar de nuevo.
