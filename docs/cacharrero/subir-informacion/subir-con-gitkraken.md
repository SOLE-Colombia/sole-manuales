# Subir cambios con GitKraken

## Paso a paso

1. Abrir repo y hacer `Pull`.
2. Editar contenido en Obsidian.
3. Revisar `Unstaged files`.
4. Pasar a `Stage` solo cambios correctos.
5. Commit descriptivo.
6. Push.

## Buenas practicas

- Pull adicional antes de push si paso mucho tiempo.
- Evitar editar el mismo archivo en paralelo con otra persona.
