# Introducción

Este portal es el manual interactivo de SOLE Colombia para gestionar contenidos, operación técnica y usabilidad de la página.

## Qué vas a lograr aquí

- Instalar y usar el entorno de trabajo según tu sistema operativo.
- Editar contenidos sin depender de comandos técnicos complejos.
- Publicar cambios con flujo controlado usando GitHub Desktop o GitKraken.
- Entender cómo se despliega y mantiene la infraestructura del sitio.

## Ruta recomendada

1. Instalación en tu sistema.
2. Inicio rápido de 5 minutos.
3. Flujo editorial no técnico.
4. Checklist de publicación.
5. Política de turnos y gobernanza.

## Públicos del manual

- **No técnico:** edición en Obsidian y publicación guiada.
- **Técnico:** arquitectura, despliegue y operación local.
- **Coordinación:** control de turnos, vigencia y calidad documental.
