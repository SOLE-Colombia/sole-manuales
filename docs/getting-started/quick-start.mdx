# Inicio rápido

Si necesitas arrancar rápido, sigue esta secuencia mínima.

<StepCard number={1} title="Sincroniza antes de empezar">
Haz `Fetch` + `Pull` en tu cliente Git visual para evitar conflictos.
</StepCard>

<StepCard number={2} title="Edita solo tu bloque">
Abre Obsidian y trabaja únicamente en la carpeta o archivos asignados.
</StepCard>

<StepCard number={3} title="Publica de forma segura">
Revisa cambios, haz commit descriptivo y luego push.
</StepCard>

## Checklist express

<ChecklistItem>Estoy en el repositorio correcto</ChecklistItem>
<ChecklistItem>Solo seleccioné cambios intencionales</ChecklistItem>
<ChecklistItem>No hay marcadores de conflicto</ChecklistItem>
<ChecklistItem>Avisé cierre de turno al equipo</ChecklistItem>

<TroubleshootBox>
Si recibes `push rejected`, no fuerces el envío. Haz `Pull`, resuelve conflicto y vuelve a publicar.
</TroubleshootBox>
