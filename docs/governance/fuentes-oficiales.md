# Fuentes oficiales y legacy

## Fuentes oficiales

1. Manuales en este portal.
2. Documentación técnica y editorial vigente.
3. README e índices principales de proyecto.

## Fuentes legacy

No se consideran operativas:

- `docs/legacy/trash/`
- `docs/tecnico/legacy_ref/`
- Guías que dependan de flujos retirados.

## Regla de prioridad

1. Manual interactivo vigente.
2. Documentación técnica/editorial activa.
3. Referencia histórica (solo consulta).
