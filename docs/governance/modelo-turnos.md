# Modelo de turnos y bloques

## Regla operativa

Una persona activa por bloque de contenido a la vez.

## Bloques recomendados

- A: contenidos técnicos.
- B: contenidos inspiracionales.
- C: glosario.
- D: contenidos desconectado/FAQ.
- E: assets multimedia.

## Flujo de reserva

1. Crear issue con la plantilla `reserva-bloque`.
2. Marcar estado `en-trabajo`.
3. Publicar cambios y cerrar turno.
4. Actualizar estado a `completado`.

## Evitar conflictos

- Pull antes de editar.
- Commits pequeños y enfocados.
- No mezclar bloques distintos en un solo commit.
