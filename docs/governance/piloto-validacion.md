# Piloto de validación

## Objetivo

Validar que el manual funciona para perfiles técnico y no técnico antes del lanzamiento formal.

## Escenario 1: perfil no técnico

- Instalar herramientas.
- Editar un contenido.
- Publicar con GitHub Desktop o GitKraken.
- Completar checklist.

## Escenario 2: perfil técnico

- Ejecutar build local.
- Revisar workflow de deploy.
- Verificar salida publicada.

## Criterios de aceptación

- Navegación clara de inicio a publicación.
- Sin enlaces rotos.
- Tiempo de adopción inicial bajo.
- Flujo de turnos entendido por el equipo.
