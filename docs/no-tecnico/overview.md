# Manual no técnico

Este módulo está pensado para personas que editan contenido sin trabajar en código.

## Ruta recomendada

1. Revisa software e instalación.
2. Sigue el flujo editorial diario.
3. Elige tu cliente Git visual (GitHub Desktop o GitKraken).
4. Publica con checklist de seguridad.
5. Aplica política de colaboración por turnos.

## Glosario rápido

- `pull`: traer cambios del repositorio remoto.
- `commit`: guardar un bloque de cambios con mensaje.
- `push`: subir commits al remoto.
- `branch`: línea de trabajo separada.
- `conflicto`: choque entre cambios del mismo archivo.
