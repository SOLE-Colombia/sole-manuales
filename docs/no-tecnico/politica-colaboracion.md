# Política de colaboración y conflictos

## Regla principal

Una persona trabaja por bloque a la vez para reducir conflictos.

## Bloques sugeridos

- Bloque A: `content/es/solve/`
- Bloque B: `content/es/inspire/`
- Bloque C: `content/es/glossary/`
- Bloque D: `content/es/disconnected/` y `content/es/answers-comments/`
- Bloque E: `content/assets/`

## Protocolo de turno

1. Tomar turno en el canal definido.
2. Declarar carpeta o archivos a editar.
3. Hacer Pull antes de iniciar.
4. Editar y publicar.
5. Liberar turno con mensaje de cierre.

## Manejo de conflicto

1. No forzar push.
2. Guardar respaldo local del texto.
3. Coordinar con quien publicó último.
4. Resolver y publicar un commit de reconciliación.
