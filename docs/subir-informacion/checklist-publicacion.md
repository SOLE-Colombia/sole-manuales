# Checklist de publicacion

Antes de cada commit/push:

- [ ] Archivo en carpeta correcta.
- [ ] Frontmatter completo.
- [ ] Enlaces e imagenes funcionan.
- [ ] Solo cambios intencionales en stage.
- [ ] Sin conflictos abiertos.
- [ ] Commit con objetivo claro.
- [ ] Push exitoso.
- [ ] Aviso de cierre al equipo.
