# Flujo editorial

## Secuencia diaria

1. `Fetch` + `Pull` en cliente Git visual.
2. Editar solo archivos asignados.
3. Revisar enlaces y formato.
4. Commit claro y pequeno.
5. Push y aviso de cierre de turno.

## Regla de oro

No mezclar cambios de varias tareas en un solo commit.
