# Laboratorio de Markdown

Usa este ejercicio para practicar antes de publicar en contenido real.

## Ejercicio guiado

1. Crea un archivo nuevo de prueba.
2. Agrega un titulo y dos secciones.
3. Inserta una lista y un enlace.
4. Inserta una imagen con texto alternativo.
5. Guarda, revisa diff y elimina el archivo de prueba si no se necesita.

## Criterio de salida

Puedes crear una nota simple sin ayuda y publicarla sin errores de formato.
