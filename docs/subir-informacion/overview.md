# Subir informacion a Voltaje

Ruta para personas no tecnicas que crean o actualizan contenido en Voltaje.

## Objetivo

- Editar contenido de forma segura.
- Publicar cambios con flujo guiado.
- Evitar conflictos entre personas del equipo.

## Ruta recomendada

1. Instalar herramientas segun sistema operativo.
2. Seguir flujo editorial.
3. Elegir cliente Git visual.
4. Practicar Markdown.
5. Publicar con checklist.
