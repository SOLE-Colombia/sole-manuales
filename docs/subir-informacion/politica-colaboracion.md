# Politica de colaboracion

## Regla principal

Todos pueden editar, pero la publicacion final requiere aprobacion.

## Aprobadores

- Direccion de Voltaje
- Gestion del conocimiento

## Protocolo

1. Tomar turno y declarar archivos.
2. Pull antes de editar.
3. Commits pequenos.
4. PR para revision.
5. Merge solo con aprobacion requerida.

## Si hay conflicto

- No forzar push.
- Coordinar con la persona que publico ultimo.
- Resolver y dejar un unico commit de reconciliacion.
