# Infraestructura distribuida

## Resumen

- Sistema estático generado con Quartz/Docusaurus según el repositorio.
- Fuente editorial en Markdown + assets.
- Build en CI y publicación en repositorio de destino o Pages.
- Hosting público con dominio propio.

## Componentes clave

- Configuración de sitio.
- Motor de build.
- Repositorio fuente.
- Pipeline CI/CD.
- Hosting de salida.

## Flujo conceptual

1. Editar contenido.
2. Validar cambios.
3. Ejecutar build.
4. Publicar artefactos estáticos.
5. Exponer vía dominio.
